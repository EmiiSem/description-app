## Проект "Словарь" на React

Этот мини-проект представляет собой простой и интерактивный "Словарь", созданный на React. Он позволяет пользователю добавлять новые слова и их определения через удобную форму. Слова и их значения отображаются в виде списка, позволяя быстро ознакомиться с созданным словарем.

<hr />

Технологии при разработке: <br />
<ul>
    <li>HTML</li>
    <li>Препроцесс SCSS</li>
    <li>React JS</li>
    <li>Пакетный менеджер NPM</li>
    <li>Сборщик проекта Vite</li>
</ul>

<hr />

## Как запустить проект:

Скачиваем файлы проекта, либо клонируем репозиторий командой:
<br />
git clone <ссылка на репозиторий>
<br />

Пишем в консоли команду:
<br />
npm run dev
